Perzian is a desktop workspace for parallel coding agents. You talk to one lead agent. It splits the work into sessions, each in its own git worktree, and brings back status, decisions and verified results instead of walls of text.

Agents got fast. Keeping up with them didn't.

Too many tabs

Five sessions across three repos means five terminals to poll and a context switch every time one of them stops.

Too much text

Figuring out what an agent did, or why it is stuck, means scrolling through pages of transcript and diff.

Claims you can't check

"All tests pass" is only as good as the agent saying it. In our own testing, an agent reported a command that exited with code 3 as passed.

How it works

  1. 1

    Tell Perzian what to build

    Describe the work in one message. The lead agent splits independent tasks into separate coding sessions.

  2. 2

    Sessions run in parallel

    Each session gets its own git worktree and branch, on the agent and model you pick. Nothing steps on anything else.

  3. 3

    You decide and verify

    Choices arrive as one-click cards. Finished work arrives as an outcome with the changed functions and checks that actually ran.

Verified, not claimed

Proof comes from what ran, not what the agent says.

Perzian watches the test, build and typecheck commands each agent runs and records the real exit code. Checks it observed read as facts. Anything the agent only reported is marked as a claim.

Changes at the function level

Know what changed before you open a diff.

The change map is built from git and tree-sitter, not from the model's summary. Every file shows its size of change and the functions and classes that were added, modified or removed. Click any file for a read-only, highlighted diff.

Decisions, not paragraphs

When an agent needs you, it asks with a card.

Questions arrive with two or three options and a one-line tradeoff each. Permission prompts become Allow, Always or Deny. Answer with a click, or press 1, 2 or 3 without leaving the keyboard.

A worktree per session

Parallel sessions on the same repo get their own branch and folder. Your checkout stays clean.

Any model, per session

Pick the agent, model and permission mode for each session and for the lead agent.

Picks up where you left off

Restart the app and sessions reattach to their conversations. A strip shows what finished while you were away.

Bring your Claude Code sessions

Import recent sessions from Claude Code and continue them in Perzian.

Cues outside the window

A dock badge counts what needs you, and notifications fire when a session finishes or asks something.

Read-only code, on purpose

Perzian is not another editor. Code is there to inspect; changes go through agents or your own editor.

Open source, and built to wrap, not replace.

Perzian drives existing agents over the Agent Client Protocol and uses your own subscriptions. It doesn't resell compute or run its own agent loop. MIT licensed.
